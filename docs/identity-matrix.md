# Primitive identity

ReplicaQuorum is an incremental multi-reviewer reproduction registry. It is not a bilateral custody transfer, claim-and-appeal judge, forecast market, document merge, source drift monitor, or simple rubric gate.

| Mechanism dimension | ReplicaQuorum |
| --- | --- |
| Roles | Study creator, predeclared reviewer set, permissionless finalizer |
| Frozen state | Artifact and method content digests before any report |
| New evidence | One fetched reproduction report per authorized reviewer |
| Consensus boundary | Semantic fidelity of four exact quotes and a bounded outcome |
| Aggregation | Deterministic multi-report threshold with explicit failure precedence |
| Liveness | Quorum close or deadline-based permissionless close |
| Terminal states | REPRODUCED, CONTESTED, INCONCLUSIVE, or CANCELLED |

The distinct primitive is quorum-based reproduction over immutable inputs. Earlier account contracts evaluate a single case, compare document versions, route consent, or transfer custody; they do not accumulate reviewer-bound replication attempts into a permissionlessly finalizable result.
